# Análisis de Rentabilidad por Género Cinematográfico

Proyecto de análisis de datos enfocado en identificar oportunidades de optimización de precios e inventario a partir de la relación entre demanda e ingresos.

## Herramientas utilizadas
- PostgreSQL
- SQL (JOIN, GROUP BY, SUM, AVG)
- Power BI

## Objetivo del análisis
Determinar qué géneros cinematográficos generan mayor rentabilidad, diferenciando entre alta demanda y alto ingreso, para apoyar decisiones de negocio orientadas a la maximización de ingresos.

## Métricas analizadas
- Veces rentadas por género
- Ingresos totales
- Ingreso promedio por renta
- Días reales vs días permitidos de renta

## Resultado
El análisis permite identificar géneros que funcionan como generadores de volumen frente a aquellos que sostienen el ingreso, proponiendo una estrategia de precios basada en comportamiento del cliente y rentabilidad.
## Actualización de análisis
- Se agregó análisis de concentración de ingresos por cliente
- Se incorporó segmentación de clientes activos vs poco activos
- Se optimizaron métricas de rentabilidad por género
